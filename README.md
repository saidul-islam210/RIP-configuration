##Project Overview

This project demonstrates the configuration of RIP (Routing Information Protocol) using Cisco Packet Tracer.

Objectives

Configure RIP on multiple routers.

Enable dynamic routing between different networks.

Establish communication between connected networks.

Verify routing tables and network connectivity.

Tools Used

Cisco Packet Tracer

Cisco Routers

RIP (Routing Information Protocol)
